# Подписи к диаграммам

01_accuracy: исходный энкодер 90,78%, с адаптером 93,17%, прирост 2,39 п.п.
Это Accuracy@1 на 586 синтетических запросах из 293 исходных фотографий.
Это также доля правильных первых ответов в этом синтетическом тесте.

02_macro_f1: 92,50% → 94,74%. Сохранённый расчёт scripts/calibrate.py усредняет
F1 только по целевым классам test (293), хотя кандидаты выбираются из 1970 вин.
Классы, встречающиеся только в предсказаниях, в это среднее не входят. Поэтому
значение не следует выдавать за macro-F1 по объединению всех истинных и
предсказанных классов или за официальную метрику организаторов.

03_public_latency: исторический локальный прогон API по трём публичным фото,
каждое отправлено дважды. Среднее 1,054 с, p50 1,056 с, p95 1,121 с.
Все шесть измерений меньше 3 с. Показатель включает локальный HTTP-запрос;
не описывает мобильную сеть, холодный запуск, параллельную нагрузку или
нынешний сервер Selectel. p95 при шести точках совпадает с максимумом.

На публичном наборе нет доступных эталонных ответов: его Accuracy, F1 и доля
правильных совпадений не вычислены. Успешный HTTP 200 не означает правильный slug.
Значения 90–100% из требований являются целевыми, а не измеренными на нём.

Диаграммы созданы из сохранённых результатов без нового запуска модели.
Исходники: artifacts/experiment/calibration.json, artifacts/api_benchmark.json.
Повторная генерация: python scripts/plot_results.py (нужны matplotlib и numpy).
PNG — для вставки в презентацию, SVG — для масштабирования, CSV — числа графиков.
