# Результаты первого обучения, 22 сентября 2026

Обучен остаточный визуальный адаптер с 394240 параметрами поверх замороженного энкодера `google/siglip2-base-patch16-384`. Полное дообучение энкодера не выполнялось.

## Данные и методика

Из 4147 строк CSV получены 2103 уникальных slug. После исключения неоднозначных связей, конфликтов содержимого, отсутствующих файлов и двух неподходящих по геометрии изображений использованы 1970 предварительно сопоставленных эталонов. Связи по именам не прошли полную ручную проверку.

Разделение по хешу исходного файла: 1382 вина для обучения, 295 для validation, 293 для test. Для каждой фотографии извлечены признаки бутылки, эвристической области этикетки и двух синтетически искажённых видов. Производные validation/test не участвуют в оптимизации. Эталоны всех 1970 вин доступны в галерее поиска. Близкие серии могут пересекать части выборки; это не проверка переноса на новые серии.

Обучение: AdamW, learning rate 0.0001, weight decay 0.01, батчи до 128 разных вин, температура 0.07, 15 эпох, seed 42. Энкодер использует GPU FP16, адаптер обучается в FP32. Оборудование — NVIDIA RTX 5070, PyTorch 2.11.0+cu128. Извлечение 7880 векторов заняло примерно 4 минуты 15 секунд после подготовки изображений; обучение небольшого адаптера по готовым векторам занимает секунды.

## OCR и гибрид

Построен локальный OCR-индекс для всех 1970 эталонов. На той же синтетической схеме OCR-only показал Accuracy@1 42.32% и macro-F1 44.87%. Смешивание визуального и текстового рангов проверено на validation; лучшим оказался вес OCR 0, то есть исходный визуальный результат. На test выбранный вариант сохранил Accuracy@1 93.17% и macro-F1 94.74%.

При выбранном весе 0 OCR не меняет визуальное ранжирование победителя, но продолжает выполняться и влияет на статус продуктового ответа через согласие рангов. Снижение риска ошибки этим правилом не измерено. Визуальный порог в гибридном статусе не проверяется; пустой OCR может вернуть нулевые совпадения. Это не откалиброванный отказ для неизвестных вин. Калибровка использует отдельные синтетические представления, тогда как API объединяет четыре кропа: её пороги нельзя считать проверенными для рабочего API без повторной оценки.

## Публичный HTTP-прогон

Локальный прогретый API обработал все три запроса и вернул непустые slug в требуемом формате. Финальный последовательный замер гибридного сервиса по трём фото, повторённым дважды: mean 1054 мс, p50 1056 мс, p95 nearest-rank 1121 мс, min 991 мс, max 1121 мс. Шесть измерений не заменяют нагрузочный тест и не доказывают SLA на других фотографиях/оборудовании. Некорректное изображение возвращает HTTP 400.

Ответы сохранены в `artifacts/public_predictions.jsonl`. Использован собственный Windows-совместимый клиент с теми же полями результатов; официальный Bash-скрипт не запускался.

Визуальная сверка обнаруживает несоответствия предсказаний надписям на фотографиях. В CSV есть винодельня «Табия», но нет карточки «Табия Пино Нуар 2025»; есть вина ARISTOV, но нет DONUM XXIV. Карточка «Мускатель Массандра белый» присутствует, однако CV путает её с той же серией. Это повод проверить покрытие и связи каталога. Закрытые ответы организатора недоступны, поэтому Accuracy/F1 публичного набора не рассчитаны.

Полевое качество остаётся неподтверждённым. Для его оценки необходимы проверенные связи каталога, реальные размеченные снимки и отдельная проверка неизвестных вин. Ближайший результат поиска является кандидатом, а не гарантированным распознаванием.

## Дополнительный эксперимент: локальные детали

Проверен SIFT + RANSAC для повторного ранжирования 40 визуальных кандидатов. Метод и построенный индекс находятся в `wine_ml/local_features.py`, результаты — в `artifacts/geometry_ablation.json`. Эксперимент использует публичные неразмеченные изображения для разбора ошибок, а не независимой оценки точности.

Первый и третий снимки не дали сильных геометрических совпадений. На втором совпадает общее оформление серии «Массандры»: геометрическое ранжирование поднимает «Портвейн белый Гурзуф», хотя видимая надпись — «Мускатель Массандра белый». Этот эксперимент не подтвердил полезность включения геометрии в основной API; она оставлена отдельным диагностическим инструментом. Для таких пар нужно различать текст и проверять корректность каталога. Обученный адаптер и его измеренный синтетический результат остаются без изменений.

## Артефакты

- `artifacts/base_model/`: исходные веса, настройки обработки, immutable revision и SHA256.
- `artifacts/experiment/adapter_best.pt`: адаптер эпохи 13, используемый поиском.
- `artifacts/experiment/adapter_last.pt`: веса после 15 эпох.
- `artifacts/experiment/index.pt`: 3940 эталонных векторов, по два на slug; содержит контрольные суммы совместимых файлов.
- `artifacts/experiment/manifest.json`: данные и разделение; `excluded.json`: исключённые карточки.
- `requirements.lock.txt`: фактически установленные версии.

Код поиска — `wine_ml/predict.py`, API — `wine_ml/api.py`, обучение — `wine_ml/experiment.py`. Инструкции запуска находятся в README.
